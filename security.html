Security

安全性・連携解除

加盟店が共有しないもの

  • Squareのログインパスワード
  • Personal Access Token
  • 購入者のカード番号・セキュリティコード

Square接続

加盟店自身がSquareのOAuth画面で要求権限を確認し、連携を許可します。BRIDGEは対象加盟店・店舗を分離して管理します。

処理上の制御

  • 適格なFAILED決済のみ
  • 購入者本人の意思による再決済
  • 購入者への上乗せ0円
  • 二重決済防止
  • 返金・紛争・不整合時の安全停止
  • 処理記録と日次照合

連携解除

加盟店はSquareの管理画面から対象アプリの連携を解除できます。解除後は新たな処理を停止し、法令・会計・紛争対応等に必要な記録を除き、不要な情報を整理します。

障害・不審な動作

不審な通知、金額不一致、二重決済の疑い等がある場合は、対象取引を操作せず、会社・店舗名と発生状況をメールでお知らせください。
