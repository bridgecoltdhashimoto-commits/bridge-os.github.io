Security & Verification

安全性・検証状況・連携解除

加盟店がSquare連携を判断できるよう、共有しない情報、処理制御、確認済み事項、解除方法を公開します。

加盟店が共有しないもの

  • Squareのログインパスワード
  • Personal Access Token
  • 購入者のカード番号・セキュリティコード

Square接続

加盟店自身がSquare OAuth画面で要求権限を確認し、連携を許可します。BRIDGEは対象加盟店・店舗を分離して管理します。

処理上の安全制御

  • 適格なFAILED決済のみを対象
  • 購入者本人の意思による再決済
  • 購入者への上乗せ0円
  • 正常決済・既回収との重複防止
  • 返金・紛争・不整合時の安全停止
  • 処理記録と日次照合

確認済み事項

Sandbox100円のFAILED決済から購入者本人による100円再決済、8円Application Fee、購入者上乗せ0円、二重決済0件を確認。
Production pilotWorker ACTIVE、OAuth接続、Webhook 1件・Enabled・7イベント、active pilot 1件を確認。
通知・実決済技術確認時の実決済0件、顧客通知0件、Gmail再送0件。
未確認外部加盟店での自然発生FAILED回収、実回収率、継続的な成果報酬受領。
技術環境の確認と、商用実績の確認は分けて表示しています。回収率や売上を保証するものではありません。

連携解除

加盟店はSquareの管理画面から対象アプリの連携を解除できます。解除後は新たな処理を停止し、法令・会計・紛争対応等に必要な記録を除き、不要な情報を整理します。

障害・不審な動作

不審な通知、金額不一致、二重決済の疑い等がある場合は、対象取引を操作せず、会社・店舗名と発生状況をメールでお知らせください。
