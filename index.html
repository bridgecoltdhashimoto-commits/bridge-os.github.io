決済エラーで失った売上に、
もう一度だけ機会を。

Squareで「FAILED」となった適格な決済だけを対象に、購入者本人が内容を確認し、自分の意思で再決済できる機会を提供する成果報酬型サービスです。

Problem

決済失敗は、そのまま売上損失になることがあります。

忙しい現場での個別確認や連絡を減らし、回収できる可能性がある売上だけを安全に再案内します。

01

FAILEDだけを対象

Square上で適格と確認できる決済失敗のみを対象とし、正常な決済には触れません。

02

購入者が自分で判断

カードを勝手に再試行せず、購入者本人が内容を確認したうえで再決済します。

03

回収成功時だけ費用発生

回収できなければ成果報酬は0円。固定費をかけずに試せます。

Flow

導入後の流れ

SquareアカウントのパスワードやPersonal Access Tokenを共有する方式ではありません。

加盟店がSquare画面で連携を許可

必要な権限を確認し、加盟店自身がOAuth認可します。

適格なFAILED決済を検知

自然発生した決済失敗のうち、条件を満たすものだけを処理します。

購入者へ再決済の機会を案内

購入内容と金額を確認し、購入者本人の意思で再決済します。

回収成功時に8％を自動分配

成果報酬はSquare Application Feeで処理されます。

Pricing

費用は回収できた時だけ。

8％ / 回収成功額
  • 初期設定費用 0円
  • 月額固定費 0円
  • 回収できなかった場合 0円
  • 購入者への上乗せ 0円

通常のSquare決済手数料は、加盟店とSquare間の契約条件に従います。

Safety

信用を言葉ではなく、制御で補います。

小規模な会社のサービスでも安全性を判断できるよう、禁止事項と停止条件を明確にしています。

✓

自動再課金なし

保存カードへの無断再試行や、加盟店に代わる強制請求は行いません。

✓

二重決済を防止

既に完了した決済や処理済み案件を再度請求しないための重複防止を行います。

✓

異常時は安全停止

返金・紛争・整合性不一致などを検知した場合は、処理を継続せず停止します。

✓

必要最小限の権限

SquareのOAuth画面で、加盟店が要求権限を確認してから連携します。

✓

いつでも連携解除

加盟店はSquare側の管理画面からアプリ連携を解除できます。

✓

FAQ

よくある確認事項

勝手に顧客のカードへ再請求されませんか？

されません。購入者本人が内容と金額を確認し、自分の意思で再決済する方式です。

回収できなくても費用がかかりますか？

成果報酬は発生しません。初期費用・月額固定費も0円です。

Squareのログイン情報を渡す必要がありますか？

ありません。加盟店自身がSquareのOAuth認可画面で、要求される権限を確認して連携します。

どの加盟店でも利用できますか？

すべてのFAILED決済が対象になるわけではありません。Square上の決済情報と購入者への案内条件を確認し、pilot対象として適合するかを事前に判断します。

導入後に停止・解除できますか？

できます。限定pilotでは安全停止を優先し、Square側からの連携解除も可能です。
